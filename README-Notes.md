# Bags Buffs & Buttons // Notes

> Where Bags Buffs & Buttons departs from the Gogo1951 add-on Style Guide, kept so no review raises it again.

## Exceptions

### Feature switches on each add-on's heading page

- **Departs from:** OPTIONS PANEL → Main Page Layout, the root panel's Features and Key Bindings sections.
- **Instead:** Each merged add-on (Connoisseur, Restocker, Thanks for the Buff, Spellbook) has a heading page under the root that holds its own on/off switches and key bindings, and the root holds only the welcome and mini-map toggles and /Commands.
- **Why:** Bags Buffs & Buttons is four add-ons in one, and the maintainer keeps each one's settings together under its own name.
